# 👻 GhostHub

Анонимные комнаты для быстрого обмена текстом и файлами между устройствами.

Нужно быстро перекинуть что-то с компьютера на телефон? Создайте комнату, откройте
ссылку или отсканируйте QR-код на другом устройстве — и обменивайтесь сообщениями
и файлами в реальном времени.

## Возможности

- 🚀 Создание комнаты по ссылке, срок жизни задаётся через `ROOM_TTL_SECONDS`
- 📱 QR-код ссылки — вход со смартфона по сканированию
- 💬 Обмен текстовыми сообщениями и файлами в реальном времени (SSE + htmx)
- 📦 Лимит объёма файлов в комнате — `ROOM_MAX_BYTES` (по умолчанию 150 МБ)
- 🔒 Опциональный пароль комнаты (пароль хешируется pbkdf2)
- 🎭 Каждому устройству автоматически присваивается своя иконка и цвет
- 🧹 Комната и все файлы автоматически удаляются после истечения срока

## Стек

Python 3.12 · Litestar 2.x · Granian · SQLAlchemy 2 (async) · Alembic · SQLite
· Jinja2 · htmx 2 (SSE) · qrcode

## Запуск

```bash
uv sync
cp .env.example .env   # и укажите свои значения
alembic upgrade head
granian --interface asgi app.main:app --host 0.0.0.0 --port 8000
```

Приложение будет доступно по адресу `http://localhost:8000`.

Для разработки можно запускать с `--reload`:

```bash
granian --interface asgi app.main:app --host 0.0.0.0 --port 8000 --reload
```

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DATABASE_URL` | — | URL базы данных (SQLAlchemy async), например `sqlite+aiosqlite:///ghosthub.db` |
| `SECRET_KEY` | `dev-secret-change-me` | Секрет для подписи cookie доступа к комнатам — **смените на свой!** |
| `STORAGE_PATH` | `storage` | Каталог для хранения файлов комнат |
| `ROOM_TTL_SECONDS` | `3600` | Время жизни комнаты в секундах |
| `ROOM_MAX_BYTES` | `157286400` | Максимальный суммарный объём файлов в комнате (150 МБ) |
| `ROOM_CLEANUP_INTERVAL_SECONDS` | `60` | Как часто фоновая задача удаляет истёкшие комнаты |
| `PUBLIC_BASE_URL` | (пусто) | Абсолютный базовый URL для ссылок и QR-кодов (если приложение за прокси) |
| `DEBUG` | `false` | Режим отладки |

## Тесты

```bash
uv run pytest
```

Тесты используют отдельную временную базу данных и каталог хранилища,
не затрагивая рабочее окружение.

## Структура

```
app/
  common/        # утилиты: время, безопасность, устройства, хранилище, шаблоны
  core/          # конфиг, sse-хаб, фоновая очистка
  database/      # engine, сессии
  modules/
    room/        # комнаты: страницы, QR, SSE, вход по паролю
    buffer/      # сообщения и файлы
  templates/     # jinja2-шаблоны
  static/        # css/js
migrations/      # alembic
tests/           # pytest
```
